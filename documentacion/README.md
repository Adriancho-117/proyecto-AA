#  Proyecto: Gestor Modular de Estudiantes

Aplicación modular en **Python** que implementa:
- Programación funcional
- Algoritmos de **ordenamiento** (Insertion Sort)
- Algoritmos de **búsqueda** (Lineal y Binaria)
- Pruebas automatizadas con **unittest**

---

## 📁 Estructura del proyecto

proyecto_estudiantes/
│
├── main.py
├── estudiantes.py
├── ordenamiento.py
├── busqueda.py
│
├── test/
│ └── test_app.py
│
└── README.md

---

##  Algoritmos implementados

### 🔹 Ordenamiento: **Insertion Sort**
- Complejidad promedio: **O(n²)**
- Uso: ordenar estudiantes por nota o código

---

### 🔹 Búsquedas
| Tipo | Complejidad | Cuándo usar |
|------|-------------|-------------|
| **Lineal** | O(n) | Lista pequeña o sin ordenar |
| **Binaria** | O(log n) | Lista ordenada |
